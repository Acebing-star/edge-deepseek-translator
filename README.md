# DeepSeek 网页翻译（Edge / Chrome 扩展）

用 DeepSeek 大模型实时翻译整个网页。双语对照、仅译文、动态内容跟随、划词翻译，全部在本地运行。

---

## 一、安装（3 步，1 分钟）

1. 打开 Edge，地址栏输入 `edge://extensions/` 回车。
2. 打开左下角的 **「开发人员模式」** 开关。
3. 点 **「加载解压缩的扩展」**，选择本文件夹（`edge-deepseek-translator`，就是含有 `manifest.json` 的那一层）。

装好后建议点一下工具栏的拼图图标 🧩，把「DeepSeek 网页翻译」固定到地址栏旁边。

> Chrome 用户同理，地址是 `chrome://extensions/`，同样开启「开发者模式」→「加载已解压的扩展程序」。

---

## 二、配置 API Key

首次安装会自动弹出设置页（没弹就点扩展图标 → 底部「设置」）。

1. 打开 <https://platform.deepseek.com/api_keys>，登录后创建密钥，复制形如 `sk-xxxxxxxx` 的字符串。
2. 粘贴到 **API Key** 输入框。
3. 点 **「测试连接」**，看到绿色「连接成功 · deepseek-chat · xxx ms」就可以了。

**关于「免费版」和「4.1」**

| 你想要的 | 实际情况 |
| --- | --- |
| 网页版 DeepSeek（聊天窗口） | 免费，但它没有公开的、免密钥的接口，扩展调不了 |
| 开放平台 API（本扩展用的） | 按 token 计费，但单价很低，日常浏览网页的花费通常在几毛钱级别；具体价格和新用户赠送额度以 <https://platform.deepseek.com> 为准 |
| 想零成本用 | 如果你手上有第三方免费/中转服务，把设置页的 **接口地址** 改成对方给的地址、填对方给的 key，模型名照对方文档填即可 |

关于模型名：默认填的是 `deepseek-chat`，代表官方当前的通用对话模型（会随官方升级指向最新版本，比如 V3.x / V4 系列）。如果你的账号能用上更新的模型（例如官方开放的 4.1 版本），直接在 **模型** 输入框里改成对应名称就行——这个框可以自由填写，不是只能选下拉项。

`deepseek-reasoner`（推理模型）也能用，翻译更准，但更慢更贵，一般不必。

## 三、怎么用

| 操作 | 方式 |
| --- | --- |
| 翻译 / 还原当前页 | 点工具栏图标 → 「翻译此页」；或按 `Alt` + `A`；或点页面右下角悬浮球 |
| 换目标语言 | 图标弹窗里的「翻译成」，或设置页 |
| 双语 / 仅译文 | 图标弹窗里的「显示方式」 |
| 划词翻译 | 直接选中一段文字，自动弹出译文气泡 |
| 右键菜单 | 选中文字右键「DeepSeek 翻译选中文本」；页面空白处右键「翻译 / 还原此页」 |

- 悬浮球可以拖到任意位置，位置会记住。
- **跳转后自动接着翻**：在同一个标签页里点链接换页、或站点内切换路由（SPA），新页面会自动翻译，不用再点一次。只限同一网站，跳到别的网站会自动停下；手动点了悬浮球关闭翻译后，该标签页也不再自动续翻。
- 页面滚动加载产生的新内容会自动接着翻译。
- 翻译期间悬浮球会转圈并显示进度，完成变紫。再点一次即还原原文。

快捷键想改的话去 `edge://extensions/shortcuts`。

## 四、几项设置说明

| 设置 | 建议 |
| --- | --- |
| 目标语言 | 默认简体中文 |
| 显示方式 | 「双语对照」最实用；「仅译文」会把原文收起（可随时还原） |
| 并发请求数 | 默认 2。遇到 429 限流就降到 1 |
| 每批字符上限 | 默认 2400。调大省请求次数但单次更慢，也更容易触发超时 |
| 附加要求 | 用来锁术语风格，例如「技术术语保留英文，括号内给中文；人名统一音译」 |
| 自动翻译 | 默认关闭。开启后每个网页打开即翻译，会持续消耗额度 |
| 跳转后继续翻译 | 默认开启。点链接换页、站点内切路由时自动接着翻，只在本标签页、本网站生效 |

## 五、常见问题

**点了翻译没反应？**
先看页面右下角有没有悬浮球。没有的话说明脚本没注入：`edge://`、`chrome://` 开头的浏览器内部页、Edge 加载项商店页面，浏览器一律禁止扩展运行，属于正常限制。普通 http/https 网站都支持。

**提示 401 / API Key 无效**
密钥复制错了或已删除。回设置页重新粘贴，注意不要带多余空格；也可以点「测试连接」单独验证。

**提示 402 余额不足**
开放平台账户余额用尽，需要充值。

**提示 429 请求太频繁**
把设置里的「并发请求数」改成 1，等一分钟再试。

**译文重复出现两遍**
页面里的文本被框架重新渲染了。点一次还原再翻译即可；如果反复出现，把该站点加入 `notranslate`（在元素上加 `translate="no"` 属性）不现实，可直接反馈给我调整。

**某些区块没被翻译**
代码块（`pre`、`code`）、输入框、以及带 `translate="no"` / `notranslate` class 的元素会被故意跳过，避免破坏页面功能和代码复制。

**翻译很慢**
首次翻译整页时按段落分批请求，页面越长越久。可以先只翻译当前文章页；翻完后同类页面第二次会走缓存。

## 六、隐私

- API Key 只存在 `chrome.storage.local`，也就是你这台电脑的浏览器本地存储里，不会同步到云端、不会发给除你在设置页填写的接口地址以外的任何服务器。
- 发给模型的只有页面上的**正文文本**，不包含浏览记录、Cookie、表单内容。
- 页面结构、脚本、图片一律不外传。
- 所有处理都在浏览器本地完成，没有自建服务器，没有埋点。

## 七、文件结构

```
edge-deepseek-translator/
├── manifest.json     扩展清单（MV3）
├── background.js     Service Worker：调用 DeepSeek 接口、右键菜单、快捷键、角标
├── content.js        页面内翻译引擎：采集段落、分批、写回译文、动态监听、悬浮球、划词
├── content.css       译文与提示条样式
├── shared.js         公共常量与设置读写
├── popup.html/css/js 工具栏弹窗
├── options.html/css/js 设置页
├── icons/            图标 16/32/48/128/256
├── make_icons.py     图标生成脚本（PIL，重新生成用）
└── tests/
    └── logic.test.js 核心逻辑断言（node tests/logic.test.js，28 项）
```

> 注意：扩展目录里**不能有以 `_` 开头的文件或目录**，Chrome/Edge 会拒绝加载（这是保留给系统用的命名）。
> 所以测试目录叫 `tests` 而不是 `_tests`，别改回去。

想改样式：译文块的外观全在 `content.css` 的 `.dsk-trans` 里，改边框颜色、缩进、透明度即可。
想改提示词：`background.js` 里的 `SYSTEM_TEMPLATE` 是翻译规则，改完在 `edge://extensions/` 点一下扩展的刷新按钮生效。
